# Literature protocol

PDFs are the primary sources; Markdown notes are working memory, not authority. Claims
must remain source-supported and should record page/section evidence when notes are
filled. Read progressively by module rather than loading all PDFs for routine coding:

- factuality: SelfCheckGPT, FActScore, fact-checking, CRITIC, and RAG;
- calibration: semantic uncertainty, LLM judges, and conformal factuality;
- dataset quality: α-Precision, β-Recall, Authenticity, targeted generation,
  data-centric evaluation, and model collapse.

Never attribute a claim to a source unless the source supports it; record page/section
evidence when notes are filled. M0.1 does not infer bibliography metadata from filenames
or summarize the supplied PDFs.
