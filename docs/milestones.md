# Milestones

- **M0 — Foundation (current):** repository, reproducibility, typed contracts, protocol
  interfaces, configuration, storage, literature inventory, CLI, and tests.
- **M1 — Baseline harness:** B1/B2/B3 implementations and a common benchmark harness.
- **M2 — Common validator architecture:** deterministic, statistical, and semantic-NLI
  validator layers.
- **M3 — Additional critics:** factual/RAG, privacy, and fairness critics.
- **M4 — Calibrated evidence fusion:** heterogeneous evidence calibration and fusion.
- **M5 — Risk-aware controller:** action selection over exactly ACCEPT, REPAIR,
  REVALIDATE, REGENERATE, and REJECT.
- **M6 — Defect-localized repair:** dependency-aware repair with revalidation.
- **M7 — Dataset-level coverage optimization:** marginal contribution and audit.
- **M8 — Optional extensions:** failure memory and cost-aware routing.
- **M9 — Complete experiments and ablations:** final evaluation and reproducibility
  package.
